# Tandem MVP — план задач

Порядок работы над каждой функцией одинаковый: **миграция (таблицы) → RLS-политики → серверные функции (RPC) → тесты → интерфейс**.
Сначала строим фундамент (дни 0–1), потом добавляем функции «вертикальными срезами»: каждая функция доходит от базы до экрана, прежде чем браться за следующую.

Отмечайте `[x]` после выполнения. Одна задача = один коммит.
Модель: 🔴 — сильная модель (база, права, безопасность), 🟢 — можно дешёвую (UI, настройка).

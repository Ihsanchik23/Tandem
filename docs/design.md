# Tandem — правила интерфейса

Единый стиль: grouped list (как настройки iOS/WhatsApp) с фирменными отличиями Tandem.
Эталон — «Настройки страницы». Весь новый UI собирается из компонентов `src/components/ui`.

## Фон и группы

- Фон всех экранов и панелей — белый. Серый фон `#F2F2F7` — только у бокового меню.
- Группа (`Section`): подпись мелким серым капсом над карточкой, карточка `#F8F6F4` (`bg-surface`), скругление 12px, без рамки.
- В боковом меню карточки белые на сером — обёртка `OnGrayBackground`, больше нигде.
- Опасные действия (архив, удаление) — отдельной группой в конце, красным текстом, с подтверждением.

## Строки и поля

- Строка (`Row`): высота 48–52px, иконка Phosphor Regular слева (20–22px), текст, значение серым справа, шеврон.
- Разделитель тонкий (0.5px), начинается от текста; у последней строки его нет.
- Строка с выбором значения (приоритет, роль) — `PopoverRow`: список открывается под строкой.
- Действие в группе («Добавить…») — строка с плюсом, текст фирменного цвета (`Row accent`).
- Поле ввода в группе (`FieldRow`): подпись мелким серым сверху, поле без своей рамки и фона (`fieldInput`).
- Выбор одного из списка — `RadioRow` (радио справа). Выбор из 2–3 вариантов — `Segmented`. Несколько из списка — `CheckRow`.
- Пояснения — иконка «i» у подписи группы (`Section info`), не текстом на странице.
- Пустые состояния и ошибки — понятным языком, ошибки красным под группой.

## Панели справа

- Шапка одна (`PanelHeader`): заголовок слева, значки действий, крестик справа. Кнопки «Закрыть» нет.
- «Отмена» и главная кнопка закреплены внизу (`PanelFooter`, проп `footer` у `Sheet`).

## Фирменное

- Акцент `#BF4A31` (оттенки `#AE3926` — наведение, `#D86750` — редко). Только для: главной кнопки, выбранного радио, активных пунктов меню, счётчиков, метки «Новая», статуса «В работе». Остальное нейтральное.
- Главная кнопка одна на всё приложение — сплошная `#BF4A31` (`PrimaryButton`, `primaryButton()`; широкая — `Button`). Градиент на кнопках не используем.
- Вторая кнопка — нейтральная (`SecondaryButton`), подтверждение опасного — красная (`dangerButton()`).
- Системный шрифт, скругления как сейчас (карточки 12px, кнопки — пилюли), иконки Phosphor Regular.

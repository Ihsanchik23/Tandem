# Tandem — правила интерфейса

Структура WhatsApp (списки, группы, минимум элементов) + форма Instagram (мягко, сильно скруглено, без рамок).
Весь новый UI собирается из компонентов `src/components/ui`. Токены цветов — в `src/app/globals.css`.

## Цвета — строго по ролям

| Цвет | Токен | Роль |
|---|---|---|
| `#1E1E1E` чёрный | `ink` | **Выбор**: выбранный сегмент, активная вкладка, выбранный фильтр-чип, выбранная строка бокового меню (текст и иконка белые). Переключатели и галочки выбора — тоже чёрные. Основной текст. |
| `#D4442A` терракота | `accent` | **Действие и внимание**: главная кнопка, счётчики непрочитанного, метка «Новая», активная иконка глобального меню, выбранное радио, плавающая «+». |
| `#BA3A23` | `accent-hover` | Только наведение и нажатие на элементы с акцентом. |
| `#FFFFFF` | `canvas` | Фон всех экранов и панелей. |
| `#F5F5F5` | `surface` | Группы, поля, поиск, второстепенные кнопки, колонки доски (цвет строки поиска на «Поиске»). |
| `#E8E8E8` | `line` | Разделители (на тон темнее `surface`); наведение на серые кнопки. |
| `#74706B` | `muted` | Второстепенный текст (контраст 4.9:1). |
| `#F2F2F7` | — | Только фон бокового меню (`GROUPED_BG`); карточки в нём белые. |

- Акцент — только чистый `#D4442A`. Других оттенков, прозрачностей (`accent/10`), градиентов и тусклых версий нет. Подсветка фокуса и выделения — нейтральная (`ink/15`).
- **Исключение:** свои сообщения в чате — пузырь сплошной `#D4442A` с белым текстом.
- Смысловые цвета остаются: приоритеты (Срочный — красный, Высокий — жёлтый), точки статусов задач, опасные действия — красный, цвета направлений на «Структуре».
- Градиент бренда — только логотип и экраны, ещё не переведённые на эти правила.

## Форма

- Кнопки, поля ввода, поиск, сегменты, чипы — таблетки (`rounded-full`). Многострочное поле — скругление 20px.
- Карточки групп и колонки доски — 20px (`rounded-[20px]`); карточки внутри (задача, подтверждение, выбор) — 16px (`rounded-2xl`).
- Никаких рамок у полей, кнопок и карточек — разделение только заливкой. Тонкие разделители между строками — можно.
- Тени — только у плавающего: правые панели, меню, поповеры, подсказки, плавающая «+», поднятая карточка при перетаскивании.
- Системный шрифт, иконки Phosphor Regular.

## Группы и строки

- Группа (`Section`): подпись мелким серым капсом над карточкой, карточка `surface`. В боковом меню — белая (`OnGrayBackground`).
- Строка (`Row`): 48–52px, иконка слева, текст, значение серым справа, шеврон; разделитель от начала текста, у последней строки нет. Выбранная (`active`) — чёрная.
- Строка с выбором значения — `PopoverRow`; действие в группе («Добавить…») — `Row accent` с плюсом.
- Поле в группе — `FieldRow` (подпись сверху, поле без фона). Отдельное поле — `TextField` (таблетка `surface`).
- Один из списка — `RadioRow` (радио акцентом); 2–3 варианта — `Segmented` (выбранный чёрный; внутри группы — `onCard`); несколько — `CheckRow`.
- Плашка иконки страницы (`PageIcon tile`) — серая на белом, белая на серой карточке (`onCard`).
- Пояснения — «i» у подписи группы (`Section info`), не текстом.
- Опасные действия — отдельной группой в конце, красным текстом, с подтверждением.

## Панели справа

- Шапка `PanelHeader`: заголовок слева, значки действий, крестик справа.
- Низ `PanelFooter` (проп `footer` у `Sheet`): «Отмена» (`SecondaryButton`) и главная (`PrimaryButton`), без линии.

## Кнопки

- Главная — одна на всё приложение: сплошная `#D4442A` (`PrimaryButton`, `primaryButton()`, широкая — `Button` / `wideButton()`).
- Второстепенная — `surface` (`SecondaryButton`), опасное подтверждение — красная (`dangerButton()`).

## Доска задач

- Колонки `surface` 20px, статус — только цветная точка у заголовка. Карточки задач белые, 16px, без теней.
- «Добавить задачу» — серая таблетка (`line`) без пунктира. На телефоне выбранная вкладка статуса — чёрная.
- «Мои задачи» отдельно не подсвечиваются (есть фильтр «Мои задачи»).
